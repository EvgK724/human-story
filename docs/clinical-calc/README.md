# Мера · ИМТ и функция почек

Мобильное приложение на русском языке для ИМТ, расчётного клиренса креатинина по Кокрофту–Голту и СКФ по CKD-EPI 2021.

- Приложение: https://evgk724.github.io/human-story/clinical-calc/
- QR: https://evgk724.github.io/human-story/clinical-calc/#qr

## Возможности

- Независимый расчёт ИМТ, клиренса и СКФ по мере ввода.
- Нормальный диапазон ИМТ, три степени дефицита массы и три степени ожирения; подсветка текущего диапазона.
- Отдельный расчёт СКФ CKD-EPI 2021 и категории G1–G5, с пояснением, почему категория сама по себе не устанавливает ХБП.
- Креатинин в мкмоль/л или мг/дл; смена единиц переводит значение, не меняя концентрацию.
- Выбор пола для коэффициента формулы; фактической, расчётной по Devine, скорректированной или заданной вручную массы.
- ИМТ всегда использует фактическую массу. Выбор расчётной массы не меняет ИМТ.
- Десятичная точка и запятая, проверка вводимых значений, очистка, явно обозначенный учебный пример, копирование результата.
- Справка с формулами, клиническими ограничениями и ссылками на WHO, CDC, NHS SPS, NKF, NIDDK и оригинальную публикацию.
- Тёмная тема, мягкие голубые заголовки, вертикальная прокрутка и меню у нижнего края, адаптация к iPhone/iPad и обеим ориентациям.
- Иконки для экрана «Домой» и локальный QR-код.

Расчёт выполняется в браузере. Приложение не использует сервер для обработки медицинских данных, localStorage, cookies или внешнюю аналитику. Ввод живёт только в памяти страницы. Копирование происходит по нажатию пользователя. Ссылки на источники открываются отдельно. Для загрузки приложения нужен интернет; офлайн-режим не заявлен.

## Медицинская модель

ИМТ = масса в кг / (рост в метрах)². Взрослые категории определяются по исходному значению, до округления. Расчётный референсный диапазон массы соответствует 18,5 ≤ ИМТ < 25 и не является индивидуальной целью.

Кокрофт–Голт: `(140 − возраст) × масса / (72 × креатинин в мг/дл)`, с коэффициентом 0,85 для женщин. `мг/дл = мкмоль/л / 88,4`. Результат — **клиренс креатинина в мл/мин**, не рСКФ CKD-EPI и не показатель, индексированный на 1,73 м². Категории СКФ не присваиваются клиренсу по Кокрофту–Голту. Креатинин не округляется эмпирически до 1 мг/дл; промежуточные результаты не округляются.

Расчёт предназначен для взрослых при стабильном креатинине; он может быть неприменим при ОПП и иных специальных состояниях. Масса для формулы выбирается клиницистом с учётом ситуации и инструкции препарата. Devine доступен при росте ≥152,4 см; скорректированная масса не вычисляется, если фактическая ниже Devine.

CKD-EPI 2021: `142 × min(SCr/κ,1)^α × max(SCr/κ,1)^−1,2 × 0,9938^возраст × F`. Для мужчин κ = 0,9; α = −0,302; F = 1. Для женщин κ = 0,7; α = −0,241; F = 1,012. Креатинин — в мг/дл, результат — мл/мин/1,73 м². Масса не используется. Категории рассчитываются до округления: G1 ≥90, G2 ≥60, G3a ≥45, G3b ≥30, G4 ≥15, G5 <15. Для диагноза ХБП изменения должны сохраняться ≥3 месяцев; G1–G2 без иных признаков повреждения почек не означают ХБП.

## Запуск и проверки

Из корня репозитория:

```sh
python -m http.server 4173 --directory docs
node --test tests/clinical-calc.test.mjs
```

Открыть http://localhost:4173/clinical-calc/.

Контрольный пример: мужчина 60 лет, 70 кг, 175 см, креатинин 88,4 мкмоль/л (1 мг/дл): ИМТ **22,86**, клиренс **77,8 мл/мин**. Для женщины при тех же данных клиренс **66,1 мл/мин**. СКФ CKD-EPI: мужчина **86,2**, женщина **64,5 мл/мин/1,73 м²**, оба значения относятся к категории G2.

Проверки: численные эталоны, точные границы категорий, преобразование единиц, ошибочный ввод и ограничения массы; браузерная проверка расчётов, копирования, очистки и навигации. Адаптация проверена в Chromium при ширинах 320–1440 px. Проверка размеров — эмуляция, не испытание на физических устройствах Apple.

Публикация: GitHub Pages, ветка `main`, каталог `/docs/clinical-calc`. Родительский `docs/sw.js` исключает это приложение из кеша Human Story.
