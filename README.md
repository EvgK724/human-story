# Human Story — История человека

Учебное приложение для телефона и планшета. 20 глав об истории человека, 100 словарных карточек с переводом и примерами, тренировки и озвучка Microsoft Ryan (`en-GB-RyanNeural`).

**Открыть:** https://evgk724.github.io/human-story/

## На iPhone / iPad

1. Откройте ссылку в Safari.
2. Нажмите «Поделиться» → «На экран Домой».
3. Откройте приложение с новой иконки при включённом интернете и дождитесь «Готово без интернета» внизу страницы.

После сохранения чтение, тренировки, словарь и все 201 аудиозапись работают без сети. Профиль и вход в ChatGPT не нужны. Если браузер удалил данные сайта, откройте приложение с интернетом и снова дождитесь сохранения.

Прогресс хранится на устройстве. Резервную копию можно сохранить и восстановить в разделе «Прогресс». При переходе с другой версии сайта перенесите прогресс через эту резервную копию: разные адреса не разделяют хранилище.

## Исходники

Статическое приложение без сборщика. GitHub Pages публикует каталог `docs/` из ветки `main`. Для локального запуска: `python3 -m http.server 4173 --directory docs`.

Материалы — самостоятельные учебные пересказы по предоставленному источнику «How It Works — The Story of Humans, 8th Edition 2026», с указанием страниц в главах. Исходный PDF не включён. В приложении нет API-ключей, серверного аккаунта и внешних ресурсов, необходимых для работы.

Версия переноса на GitHub Pages и полного офлайн-хранения: 2026-10-18-1.
